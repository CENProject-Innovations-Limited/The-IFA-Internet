What is OrisaScript?

OrisaScript (also written as Orisa-Script or OrisaScript) is the OrisaLang Algorithm (orisalgo) of the IFA Internet — the right-brained, intuitive, artistic counterpart to IfaLang (ifalgo). It generates dual symbols for any character in any language using the Duality Principle (Ojú/Òdì).
