Reading the tree

Each Odù is four lines, each line a single mark I or a double mark II — 2×2×2×2 = 16 heads.

In binary branching, the trunk splits on the first line (I → Ọ̀tún, II → Òsì), then on each following line, so the path from trunk to head spells the Odù.

In seniority, heads sit in their traditional order, Ogbè and Ọ̀yẹ̀kú crowning the tree. This order is also the Lab's learning path, from IfaScratch to IfaJulia.

Every language is named in IfaLang: the Ifa prefix plus the language it teaches (IfaScratch, IfaPython, IfaJava…).
